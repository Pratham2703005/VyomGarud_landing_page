## Animations

This project showcases advanced animation techniques using **Framer Motion**:

### Scroll-Based Animations
- **useScroll** - Track scroll progress for parallax effects
- **useTransform** - Transform scroll values to animation properties
- **useInView** - Trigger animations when elements enter viewport

## 🚀 Getting Started

### Prerequisites
- Node.js 18.17 or later
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Pratham2703005/VyomGarud_landing_page.git

# Navigate to project directory
cd vyom_garud

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
